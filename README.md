## 📝 Project description

Despite guideline recommendations for intensive lipid-lowering and blood pressure control in high-risk populations, treatment gaps and inequalities in preventive care delivery remain poorly characterised at population level. This cross-sectional analysis of linked electronic health records from the SAIL Databank (Wales, 2022–2023) quantified cardiovascular risk burden, LDL-C and SBP target attainment, treatment intensity, and preventable event burden across primary (diabetes mellitus) and secondary prevention (established atherosclerotic cardiovascular disease) populations. Patient-specific projection modelling estimated preventable cardiovascular events under incremental target attainment scenarios. Socioeconomic inequalities in risk burden, treatment receipt, and target attainment were assessed using the Wales Index of Multiple Deprivation (WIMD).
